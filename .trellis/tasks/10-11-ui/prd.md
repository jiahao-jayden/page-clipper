# 插件 UI 样式精修

## 背景
用户反馈 popup 与设置页样式"太随便"：标题区无品牌标识、预览区把 frontmatter 原样堆在等宽字体里、字段样式不一致、状态提示用 ✓/✗ 字符、主次按钮权重不清，设置页与 popup 视觉语言不统一。

## 目标（遵循 DESIGN.md "Quiet Workbench"）
- popup：品牌头部（Sage Tail 图标 + 名称 + 保存目标），来源卡片（封面/图标、标题两行截断、作者 · 域名），正文预览为主体，frontmatter 折叠可展开；备注与标签统一字段样式；标签 chip 用图标移除；底部主按钮 + outline 复制按钮；状态 toast 用图标替代 ✓/✗。
- 设置页：同一品牌头部、统一字段/区块样式、状态提示样式与 popup 一致。
- 保持 420×580 固定尺寸、仅预览区滚动。

## 非目标
- 不改抽取、Markdown 生成、消息协议；复制/保存内容不变。

## 验收
- [ ] popup 与设置页视觉统一、层次清晰
- [ ] frontmatter 默认折叠，正文为预览主体
- [ ] 键盘可达、focus 可见、状态不仅靠颜色
- [ ] `bun run build` 与 tsc 通过
